Frame Ferry

Setup

Follow the project README to install the player components and register the native host for your browser. On the browser's Extensions page, enable Developer mode, select Load unpacked, and use the extension directory printed by the installer, normally ~/.local/share/frameferry/extension.

Pin Frame Ferry or use Alt+Shift+M to open it. After updates, rerun installation and reload the extension. There are no store updates.

Playback

Continue reads the main video's position when clicked. If it cannot read a position, playback uses the URL or saved history. Play from the beginning requests zero. Live/DVR position transfer is not supported.

Browser pausing is optional and happens only after mpv confirms playback. Changed or inaccessible pages may stay playing. The resolution setting is a limit, not a guarantee; mpv shows the actual stream resolution.

Privacy

The extension stores settings locally, has no telemetry, and never reads cookies. It reads the selected page after a user action and sends a playback request to the local helper. The player contacts media providers and SponsorBlock. Logs can contain sensitive URLs; review them before sharing.

Browser-cookie access and background yt-dlp updates are off by default. They can be enabled in the local player settings described in the user guide.

Troubleshooting

Use Check native host in the popup. If it fails, reinstall for the correct browser and reload the extension. Run python3 scripts/doctor --browser helium, selecting your browser, for local checks. Playback failures may require an updated yt-dlp or account access; a host check does not test provider access.
